About the project

A campus system built
around one hard problem.

SmartCampus AI is a smart college management platform designed to bring assignment submission, verification, and administration onto one connected system. Rather than treating handwriting verification as an afterthought, it's the core engine the rest of the platform is built around.

The system is organized into a multi-module architecture — separate portals for students, staff, and institutions — each talking to a shared backend and a common AI verification pipeline, so a document submitted once can be checked, scored, and routed without manual re-entry.

This is an actively developed project. Current work covers the four core portals and the handwriting verification module; the roadmap below tracks what's shipped and what's next.

How verification works

From reference sample to staff dashboard.

A simplified view of the pipeline that turns a scanned document into a verified, reportable result.

1

Reference PDF

A known handwriting sample is uploaded to establish the writer's baseline.

2

Image Processing

Scanned pages are cleaned, deskewed, and prepared for analysis.

3

Handwriting Detection

Handwritten regions are located and separated from printed content.

4

Feature Extraction

Stroke shape, spacing, and pressure patterns are converted into measurable features.

5

Writer Profile

Extracted features are compiled into a profile unique to the reference sample.

6

Verification

The submission is compared against the writer profile to confirm or flag authorship.

7

AI Report

Results are compiled into a readable report with a confidence score.

✓

Staff Dashboard

The finished report lands in the staff portal for review and action.
